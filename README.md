## 🎯 Visão Geral

Este portfólio é um site pessoal projetado para exibir meus projetos profissionais, habilidades e conquistas. Ele serve como uma representação digital das minhas habilidades e experiência em desenvolvimento web.

## 🚀 Como Começar

### Pré-requisitos

- Um navegador web moderno (Chrome, Firefox, Safari, Edge, etc.)

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/BelmontBeta/portfolioDev.git
```

2. Navegue até o diretório do projeto:
```bash
cd portfolioDev
```

3. Abra o arquivo `index.html` em seu navegador web:
```bash
open index.html
```

Ou simplesmente clique duas vezes no arquivo `index.html` no seu explorador de arquivos.

## 💡 Uso

Este site de portfólio pode ser:

- **Visualizado localmente** - Abra `index.html` em seu navegador para ver o portfólio
- **Implantado online** - Envie para um servidor web ou plataforma de hospedagem (GitHub Pages, Netlify, Vercel, etc.)
- **Modificado** - Edite o HTML, CSS e JavaScript para personalizar o portfólio com seu próprio conteúdo

## 🎨 Personalização

Para personalizar este portfólio:

1. **Atualize o HTML** (`index.html`):
   - Altere seu nome, título e biografia
   - Adicione seus projetos e descrições
   - Atualize os links de redes sociais

2. **Modifique o Estilo** (`styles/style.css`):
   - Altere cores, fontes e layouts
   - Ajuste os pontos de quebra responsivos
   - Adicione animações personalizadas

3. **Adicione Interatividade** (`scripts/script.js`):
   - Implemente validação de formulários
   - Adicione rolagem suave
   - Crie conteúdo dinâmico
